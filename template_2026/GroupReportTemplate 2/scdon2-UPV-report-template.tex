\chapter{Introduction}\label{introduction}

\section{Dossier d'ouverture}\label{dossier-douverture}

\bigskip

Au cours des dernières années, la criminalité organisée est devenue un
enjeu majeur à l'échelle internationale. Les différences observées entre
les pays en termes de taux de criminalité soulèvent des interrogations
quant aux facteurs pouvant expliquer ces variations. Parmi ces facteurs,
les conditions socio-économiques telles que le niveau de revenu, le
chômage ou encore les inégalités sociales semblent jouer un rôle
déterminant.

\bigskip

Dans le cadre de ce projet, Narjis, Kawthar, Myriam ainsi que Younes ont
été missionnés par INTERPOL (a modifier en cas de non droit) afin de
mener une enquête sur les causes de la criminalité à l'échelle mondiale.
Cette mise en situation permet d'aborder l'analyse de manière concrète,
en mobilisant des données réelles pour répondre à une problématique
actuelle.

\bigskip

\begin{center}

\textbf{Dans quelle mesure les facteurs socio-économiques influencent-ils le taux de criminalité organisée entre pays a l'échelle l'internationale (2017/2023)?}

\end{center}
\medskip

\justifying

Cette question est particulièrement importante pour les décideurs
publics et les organisations internationales, car une meilleure
compréhension de ces relations pourrait permettre de mettre en place des
politiques de prévention plus efficaces et adaptées aux réalités de
chaque pays.

\bigskip

Ce projet s'inscrit dans le cadre des enseignements de bases de données
(TE43MI) et de sciences des données (TE44MI). Il repose sur l'analyse de
différentes bases de données afin d'identifier les facteurs explicatifs
de la criminalité et d'évaluer leur impact.

\section{Provenance des données}\label{provenance-des-donnuxe9es}

Nous avons utilisé plusieurs sources de données internationales afin
d'analyser l'influence des facteurs socio-économiques sur la
criminalité.

Les principales sources utilisées sont :

\begin{itemize}
\item
  Données de criminalité organisée :\\
  \url{https://ocindex.net/downloads}
\item
  Données socio-économiques (PIB, chômage, urbanisation) :\\
  \url{https://perspective.usherbrooke.ca}
\item
  Données d'Indice de Développement Humain (IDH) :\\
  \url{https://hdr.undp.org/data-center}
\end{itemize}

Ces données sont disponibles sous forme de fichiers \texttt{CSV/XLSX}
ainsi que code \texttt{.R}

\bigskip

À partir des jeux de données initiaux, nous avons construit trois tables
principales :

\begin{itemize}
\item
  une table \texttt{PAYS}
\item
  une table \texttt{INDICATEURS}
\item
  une table \texttt{CRIMINALITE}
\end{itemize}

Les données étant réparties dans plusieurs fichiers, nous avons regroupé
les indicateurs socio-économiques (PIB, chômage, IDH, urbanisation) dans
une seule table.

\bigskip

Afin de réduire le périmètre du projet, nous avons effectué les
filtrages suivants :

\hfill\break
Au niveau des colonnes nous avons conservé uniquement les variables
pertinentes :

\begin{itemize}
\item
  PIB par habitant
\item
  taux de chômage
\item
  taux d'urbanisation
\item
  IDH
\item
  indice de criminalité
\end{itemize}

Les autres variables ont été supprimées car non pertinentes pour
l'analyse.

\hfill\break
Pour ce qui est des lignes nous avons conservé

\begin{itemize}
\item
  les pays avec des données disponibles pour \textbf{2017 et 2023} (155
  pays)
\item
  les observations avec aucune valeurs manquantes
\end{itemize}

\bigskip

La population étudiée correspond à un ensemble de pays pour lesquels les
données sont disponibles sur les deux années étudiées.

L'unité statistique est le couple (\texttt{pays,\ année})

Chaque ligne correspond donc à un pays pour une année donnée.

Ces données permettent d'analyser les liens entre \textbf{indicateurs
socio-économiques et criminalité}, et ainsi d'apporter des éléments de
réponse aux problématiques posées.

\section{Import des données}\label{import-des-donnuxe9es}

Avant l'importation sous Python, un travail de nettoyage et
d'harmonisation a été réalisé sous Excel afin de garantir la cohérence
entre les différentes sources de données.

\bigskip

\begin{itemize}
\item
  \textbf{Uniformisation des identifiants pays} :\\
  Les pays ont été identifiés à l'aide du \textbf{code ISO (id\_pays)},
  utilisé comme clé commune entre les bases.

  \emph{Fonction excel associée} :
  \{\texttt{=RECHERCHEX(nom-pays-source!,nom-pays!code-ISO)}\}

  Pour chaque pays dont le nom présentait des différences (accents,
  majuscules, abréviations ou variations d'écriture), une vérification a
  été mise en place afin de permettre une correction manuelle au cas par
  cas.

  \emph{Fonction excel associée} :
  \{*\texttt{=SI(code\_ISO="";"A\ corriger";"OK")}\}
\item
  \textbf{Filtrage temporel} : Toutes les bases ont été filtrées pour ne
  conserver que l'année 2023 ainsi que 2017, afin d'assurer la
  comparabilité des indicateurs.
\end{itemize}

\section{La droite de régression linéaire : un premier
exemple}\label{la-droite-de-ruxe9gression-linuxe9aire-un-premier-exemple}

Si on souhaite expliquer les variations d'une variables réponse \(Y\) en
fonction d'un certain nombre de prédicteurs \(x_1,\ldots,x_p\), on peut
utiliser un modèle de régression linéaire simple (\(p=1\)) ou multiple
(\(p>1\))

\[
Y_i = \beta_0 + \beta_1 x_{1i} + \cdots +\beta_p x_{pi} + \epsilon_i, \qquad i=1,\ldots,n.
\] où l'on présuppose que les \(\epsilon_i\) sont i.i.d.~\(N(0,1)\) pour
tout \(i=1,\ldots,n\) (\(n\) étant la taille de l'échantillon).

Vous pourrez toujours consulter avec profit les Chapitre 11--13 du livre
sur R :

\url{http://biostatisticien.eu/springeR/livreR.pdf}
